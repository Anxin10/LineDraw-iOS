# 版本修正紀錄

## 1.1.10（33）— 2026-10-09

- 修正 PIN 配對已完成、資料已保存，但後續 DDI 準備被 iOS 背景工作終止時仍顯示配對失敗。改為「配對完成、必要檔案待準備」，診斷分開記錄 recordSaved 與 filesReady。
- 配對背景工作到期回呼核對當前工作身分，避免舊回呼取消其他工作。

## 1.1.9（32）— 2026-10-09

- 公開來源 Bundle ID、Runner、背景工作及 Keychain service 統一使用 `com.anxin10`，App 與產生器保持一致。
- 新識別碼視為另一個 App，須重新簽署、安裝及配對；不會自動取得原 App 的資料或 Keychain。此輪未覆蓋現有手機，未匯出已簽署 IPA。
- 修改目前來源不會移除歷史提交中的舊名稱；若要清理整個 Git 歷史，需要另外重寫歷史。

- 補上新手機安裝與個人 GitHub fork 發佈文件；專案產生器透過 LINEDRAW_TEAM_ID 取得自己的 Team，預設不寫入個人 Team。
- Release Archive／IPA 匯出成功，142 項核心測試、3 略過、0 失敗。主程式已覆蓋安裝並啟動於既有 iPhone；新手機安裝與 iOS 26.0 仍未實機驗收。公開來源 ZIP 已移除個人 Team 及隨附 Apple DDI 引用，尚未從該 ZIP 執行完整乾淨建置。

## 1.1.7（30）— 2026-10-09

- 本次失敗位於抽獎開始前。唯讀連線重測成功，簽署期限與裝置註冊有效；現有錯誤碼未提供 XCTest 原始原因，不能確定失敗根因。
- 核心 142 項測試、3 略過、0 失敗；重試政策涵蓋取消、背景、已連線、重試次數及非適用錯誤。App 編譯及安裝成功，build 30 實機唯讀檢查回報 READY，前後參加紀錄相同。實機未重現失敗，因此未驗證失敗重試分支。

## 1.1.5（28）— 2026-10-09

- 本機保存增加有上限的日期編碼快取，取消不必要的 JSON 欄位排序，保留原子保存與點擊前意圖紀錄；分開量測編碼／落盤／介面發布，避免每次觀察重複發布相同 busy 狀態。141 項核心測試，3 略過、0 失敗。
- 真實測試保存成本約降至每筆 0.27–0.41 秒，但首次畫面查詢仍有 5.62／7.85 秒長尾。最後一輪五筆 34.13 秒，不宣稱整輪穩定變快或每筆已達 3 秒；新增 Runner 原生秒數欄位供後續定位。
- 完整批次加入逐次查詢診斷：換頁未就緒、首次候選、候選變化、穩定等待、人工暫停、查詢失敗與點擊未送出，保留矩形、決策與耗時；最多 2,000 筆，批次结束匯出 device-observations.json，診斷另保留最近 20 筆原因摘要。人工等待單獨計時。
- 五筆真實診斷實測全為 SUBMITTED，合計 18.37 秒；四筆各 3 次觀察，分別為未辨識操作、首次候選、穩定候選。尚未達每筆 3 秒；先前 UX-16 的 22 次查詢無逐次資料，不能追溯補造原因。139 項核心測試，3 略過、0 失敗。
- 修正 Funbox 兌換說明「不得以…電腦版登入…兌換」誤觸登入暫停；僅對 StaticText 且同時有不得、兌換提示排除此片語，真實登入／驗證／付款控制仍阻擋。137 項核心測試，3 項略過、0 失敗。
- Debug 完整批次精簡查詢實測：新竹巨城五筆均保存 SUBMITTED，佇列 27.51 秒；四筆 3.61–4.51 秒，一筆 11.68 秒。尚未達每筆 3 秒；只代表指令成功回應，不代表中獎。一般啟動及 Release 抽選仍使用既有查詢路徑。
- 漏抽掃描增加原生 JSON、精簡 Runner 與 XML 模式選擇；XML 保留相容預設。精簡查詢兩輪實機五筆分別 8.91、9.25 秒，單筆 1.42–2.30 秒，十次均有明確結果；僅為唯讀掃描，不代表實際送出抽選已達 3 秒。
- JSON 解析保留可見性、enabled、座標、節點數、深度、文字及位元組限制。區分 JSON 與 XML 回應驗證，避免 JSON 回應被當成錯誤 XML。
- 新 Runner 端點 `GET /session/:id/linedraw/observe`：僅本機模式使用，一次原生快照，回傳有用可見節點的精簡 JSON；不提供點擊能力。檢查取得快照前後前景身分，超過節點／深度／文字限制時拒絕回應。
- 舊 Runner 沒有端點時回退 XML；解析失敗或可重試讀取錯誤回退既有查詢。連線逾時維持停止，不疊加請求。
- App 和 Runner 編譯通過；135 項核心測試，3 項略過、0 失敗。精簡查詢實測未送出抽獎，前後參加紀錄相同；JSON 對照重試首筆查詢逾時停止，尚未完成驗證。
