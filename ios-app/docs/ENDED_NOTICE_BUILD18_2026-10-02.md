# 「抽獎期間已結束」接續修正：1.1.0 build 18

## 修正行為

舊版只把底部的「已結束」視為終止狀態，沒有辨識「抽獎期間已結束」；若文字在原生提示框裡，還會被通用提示框規則暫停。

新增「抽獎期間已結束」「抽選期間已結束」「抽籤期間已結束」的完整文字辨識，容許空白、換行及句尾驚嘆號／句號。原生內文、停用按鈕及可確認包含該句的提示框都會記錄為 `ENDED`，然後接續下一筆，不將提示文字、確認或兌換當成點擊目標。

手機端快速元素查詢、完整畫面辨識、底部 OCR 備援與換頁驗證共用這組規則。已確認的結束提示框可以通過正常換頁驗證，仍保留網址回應、畫面穩定及不同優惠券網址的檢查。Mac 輔助程式也更新相同的結束辨識，原生文字已足夠時不額外 OCR。

「如果抽獎期間已結束，請參加下次活動」等說明句不會被當成結束結果。其他 App、無關提示框、登入／驗證碼要求仍保留既有處理；一般優惠券使用說明不因提及登入或付款而擋住明確的結束通知。這次沒有放寬未知按鈕的點擊範圍。

## 驗證

- Swift Core：113 項中 111 項通過，2 項外部來源測試依原設計略過。另對最終快速查詢 predicate 補驗，`EndedNoticeTests` 5 項通過。
- 手機端佇列替身：結束內文 → 結束提示框 → 正常抽選，三筆全部完成；狀態為 `ENDED / ENDED / SUBMITTED`，只對最後一筆點擊一次。
- Mac Node：72 項通過，涵蓋相同三筆接續、OCR 信心門檻、一般說明與人工處理邊界。
- iPhone Release 未簽署建置通過。
- 本次未連接 iPhone 進行真實 LINE 抽選。實際 LINE 畫面相容性仍需使用者覆蓋安裝後確認；上述佇列結果來自離線替身，不視為實機抽選結果。

更新後請繼續使用原有來源與紀錄；不要刪除 App 或清除資料。需 Mac 輔助模式的使用者，也應更新並重新啟動 `ios-wda`。
