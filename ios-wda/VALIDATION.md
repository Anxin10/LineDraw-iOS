## WDA 實際執行的八個案例

1. 底部「加入好友並參加抽獎」→ 點擊送出 → 下一筆。
2. 底部「加入好友」→ 重開同筆 →「抽選」→ 下一筆。
3. 停用狀態的「已結束」→ 略過，不點擊。
4. 「查看已領取的優惠券」→ 略過，不開啟或兌換。
5. 一般「抽選」→ 點擊送出；前五筆合計恰好三次送出、一次獨立加好友。
6. 「請輸入驗證碼」→ 暫停，不點擊。
7. 延遲三秒才顯示按鈕 → 載入後只送出一次。
8. 對可存取性隱藏的底部按鈕 → Vision OCR 辨識 → 再次辨識確認位置 → WDA 座標點擊；測試明確檢查使用的是 OCR 路徑。

全部使用獨立 bundle `com.beybladehunter.linedraw.fixture.ios`，沒有真實 LINE、登入、網路抽選或會員身份。Fixture 測試的活動時段特別設為 2020～2099，以便日後重跑；控制面板內建的真實五筆仍嚴格使用使用者提供的 2026/09/22～09/27 台北時間。

## 邏輯與本機介面涵蓋

- 五個短網址、優惠券 ID 與 Android 來源一致，保留順序。
- 時區與開放／截止邊界；拒絕沒有時區的自訂活動時間。
- 只派送允許格式的 LIFF 優惠券；清單去重；匯入失敗保留舊清單；跨 HTTP chunk 的中文字不破損。
- 區分已送出、已領取、已結束、載入逾時與待確認；紀錄依裝置與設定檔隔離。
- 重複按鈕、登入／驗證碼、系統對話框、切換 App、停用按鈕與兌換文字。
- 舊頁仍停留時不點擊；排除狀態列時鐘作為換頁依據；載入逾時只重開一次。
- 點擊回應中斷不重試；操作前保存意圖；重啟將未完成意圖轉待確認；暫停後不派送新點擊。
- 本機 Origin／Host 與 token 檢查；未連線、未同意不能開始；手動標記與清除記錄。
- 桌面／390px 窄螢幕沒有水平溢出、沒有瀏覽器 JS 錯誤，未連線時開始與截圖停用。
